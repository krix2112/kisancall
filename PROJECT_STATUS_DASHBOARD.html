⚙️ Backend API Route Inventory (Fastify)
Method & Endpoint Auth Role Description & Function
POST /bookings Farmer Atomically reserves an APMC slot and assigns a queue token.
GET /farmers/:id/queue Public/Farmer Returns live position, estimated wait time, and current queue event.
GET /mandis/:id/prices Public Fetches cached/live AGMARKNET prices for selected mandi & crop.

POST /staff/arrivals Staff/Admin Marks farmer gate arrival, records timestamp, calculates initial queue.
POST /staff/procurement Staff/Admin Submits accepted weight, grade (A/B/C), and final calculated payout.
POST /proof-events Staff/Admin Computes SHA-256 payload hash and submits on-chain transaction.
POST /voice/webhook Telephony Identifies caller phone number and injects farmer profile context into LLM.
POST /voice/tool/* (7 routes) Internal Low-latency tool execution endpoints for slot booking, price queries, and cancelations.
⛓️ Smart Contract Specification
Contract: ProofAnchor.sol
Network: Shardeum EVM Testnet
Solidity: ^0.8.20 (Gas Optimized)

Guarantees that procurement records cannot be modified retroactively by corrupt intermediaries or software glitches.

  • Stores (payloadHash => AnchoredEvent) mapping
  • Enforces single-write idempotency via non-zero timestamp guard
  • Emits EventAnchored with indexing for fast log querying
  • Integrated via Ethers.js v6 with automatic retry and timeout protection
